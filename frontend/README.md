# Project Labyrinth Frontend

Frontend for the Project Labyrinth RAG Honeypot.

## Tech Stack
- Next.js (App Router)
- TypeScript
- Tailwind CSS

## Getting Started

1. Install dependencies:
```bash
npm install
```

2. Start the development server:
```bash
npm run dev
```

3. Open [http://localhost:3000](http://localhost:3000) in your browser.

## Architecture

This frontend is designed to run independently from the backend for the hackathon demo, falling back to mock data if the API is unavailable.
